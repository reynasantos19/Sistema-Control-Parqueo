Sistema de Control de Parqueo

Este proyecto consiste en un sistema de control de parqueo realizado en C++.

El sistema permite llevar un control de los espacios disponibles y ocupados, registrar la entrada de vehículos y registrar la salida de los mismos.

Actualmente el sistema cuenta con 50 espacios de parqueo.

Funciones principales:

* Mostrar los espacios disponibles y ocupados.
* Registrar la placa de un vehículo.
* Asignar un espacio a un vehículo.
* Verificar si un espacio está disponible.
* Registrar la salida de un vehículo.
* Liberar un espacio cuando un vehículo sale.

Archivos principales:

main.cpp: contiene el programa principal.

espacios.cpp: contiene las funciones relacionadas con los espacios del parqueo.

entrada.cpp: contiene la función para registrar las entradas.

salida.cpp: contiene la función para registrar las salidas.
